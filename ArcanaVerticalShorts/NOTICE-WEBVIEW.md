# WebView protocol reference

DocumentScripts is an original minimal binding to the installed Android WebView support-library boundary. Public method/interface signatures and feature name were checked against AndroidX WebKit 1.12.1 official sources:
https://dl.google.com/dl/android/maven2/androidx/webkit/webkit/1.12.1/webkit-1.12.1-sources.jar

Source archive SHA256:47f0b2fae0b529825d2cd08c7599e42029cbe93aaffcc87240fe74ab515cb18b.
The Android Open Source Project protocol reference is Apache License2.0; no library code/private key or captured publisher payload is bundled. The implementation requires Android9+ and the provider's actual DOCUMENT_START_SCRIPT feature; absence fails explicitly. This is not a website access or security bypass.
